## 1. 快速入门

### 1.1 安装与启动

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 构建生产版本
npm run preview    # 预览构建结果
```

### 1.2 5 分钟上手流程

1. **参数配置**：输入 UPS 容量、系统电压、选定标准（IEC/UL）和材质（铜/铝）。
2. **环境注入**：设置目标项目的高温、高原或强制通风等环境条件。
3. **回路定调**：确定过载裕度、谐波冲击与容灾要求。
4. **收取报告**：查看三档报价与工艺规范，一键导出 PDF。

### 1.3 关键术语速查

| 术语 | 含义 | 快速理解 |
|------|------|----------|
| **K 系数** | 综合环境修正系数 | K = Ktemp x Kalt x Kwind |
| **负荷率** | 实际负载 / 额定载流 | 越接近 100% 越经济 |
| **修正载流** | 考虑环境后的实际载流量 | 基础载流 x K 系数 |

### 1.4 选型示例 (500kVA)

| 参数 | 值 |
|------|-----|
| UPS 容量 | 500 kVA |
| 系统电压 | 380V/220V, 三相四线制 |
| 环境温度 | 40 C |
| 海拔 | <= 1000m |
| 主路/旁路/输出电流 | 760A |
| 标准策略推荐 | 60x10mm 铜排, 修正载流 856A, 负荷率 88.8% |

## 3. 参数配置

### 3.1 设备容量与标准

| 参数 | 必填 | 取值范围 | 说明 |
|------|------|----------|------|
| UPS 容量 (kVA) | Yes | 10-5000 | 设备额定容量 |
| 系统电压 (V) | Yes | 220/380/400/415 | 相电压/线电压 |
| 相数 | Yes | 单相/三相 | 供电系统类型 |
| 适用标准 | Yes | IEC/GB 或 UL | 遵循的技术标准 |

> **UL 标准约束**：1) 风冷修正系数强制禁用 (K 无法突破 1.0)；2) 压降采用 UL 规范阻抗参数。

### 3.2 材料选择

| 材料 | 导电率 | 载流量 | 重量 | 成本 | 适用场景 |
|------|--------|--------|------|------|----------|
| **铜排 (TMY)** | 高 (100%) | 大 | 重 | 高 | 高负载、高可靠性 |
| **铝排 (LMY)** | 中 (61%) | 中 | 轻 | 低 | 成本敏感、轻载场景 |

铝排载流量按同体积铜排的约 61% 降额等效运算。

### 3.3 环境参数

#### 温度修正

| 环境温度 | Ktemp | 建议 |
|----------|-------|------|
| <= 30 C | 1.08 | 无需特殊处理 |
| 40 C | 1.00 | 标准条件 |
| 50 C | 0.91 | 需增大规格 |
| 60 C | 0.82 | 需大幅增大规格 |

#### 海拔修正

| 海拔 | Kalt | 说明 |
|------|------|------|
| <= 1000m | 1.00 | 标准条件 |
| 2000m | 0.95 | 空气稀薄，散热下降 |
| 3000m | 0.89 | 需考虑降容 |
| 4000m | 0.82 | 需大幅降容 |

#### 风冷修正

| 散热方式 | Kwind | 适用场景 |
|----------|-------|----------|
| 自然对流 | 1.00 | 标准柜体、良好通风 |
| 强迫风冷 | 1.15-1.30 | 高负载、紧凑布局 |

> **风扇失效压力测试**：启用风冷后，强烈建议点亮"风扇失效模拟"开关，验收母排结构在风机宕机时是否安全。

## 4. 回路设置

SmartBusbar 支持 **四回路** 配置：

| 回路 | 说明 |
|------|------|
| 主路输入 | UPS 主电源输入回路 |
| 旁路输入 | UPS 旁路电源输入回路 |
| 输出回路 | UPS 输出至负载的回路 |
| 中性线 | 系统中性线回路 |

### 4.1 旁路过载系数

| 系数值 | 含义 | 适用场景 |
|--------|------|----------|
| 1.0 | 额定负载 | 标准运行 |
| 1.1 | 常规余量 | 轻载运行 |
| 1.25 | 125% 过载 | IEC 62040-3 推荐 (10 分钟) |
| 1.5 | 150% 过载 | 电机类/高冲击负载 (60s) |

### 4.2 谐波负载与 N 线倍率

| 负载类型 | 谐波系数 | N 线系数 |
|----------|----------|----------|
| 标准线性负载 | 1.0 | x1.0 |
| 中等谐波 | 1.15 | x1.45 |
| 高谐波 (IT/变频器) | 1.25 | x1.73 |
| 数据中心 | 1.3 | x2.0 |

选型预警：N 线自动膨胀后，原本与相线等大的 N 排可能立即失效（报红），需使用截面倍数级的定制母排。

### 4.3 电池极回路

UPS 电池系统"电压低、电流极大"：

- 输入电池组电压、功率因数 (PF) 和逆变效率，推算放电峰值电流
- 填写电池容量 Ah 与充电倍率 (如 0.1C)，计算充电回流需求
- 引擎在"满载放电"与"大倍率充电"中**取较大值**作为推荐基准

### 4.4 物理结构衰减

| 衰减因素 | 修正系数 | 说明 |
|----------|----------|------|
| 平躺侧卧安装 | x0.92 | 散热受限 |
| IP54 防护柜 | x0.93 | 通风受阻 |
| IP65 防护柜 | x0.88 | 密封环境 |

> 当高过载、高谐波与高防护衰减同时出现，必须**手动勾选"允许母排叠加"**，解锁 2片/3片 堆叠方案。

### 4.5 电缆选型 (12 根红线)

- 单相电缆并联根数上限为 **12 根**
- 自动计入 Kp=0.8 并联分组降额系数
- 超过 12 根时停止电缆推荐，建议切换至母排方案

### 4.6 并机系统 (N+X)

- **主母排**：按 N+X 总量汇流后的极端输入进行选型
- **输出母排**：按 N 台负载总量进行选型

## 5. 选型结果与解读

### 5.1 三档推荐策略

| 策略 | 负荷率 | 适用场景 |
|------|--------|----------|
| 经济型 | 90%-100% | 成本敏感、散热良好 |
| **标准型** (推荐) | 70%-90% | 平衡成本与安全 |
| 保守型 | < 70% | 高可靠性、无冷却条件 |

### 5.2 推荐方案卡片

每个回路显示三档策略的推荐方案，包含规格、负荷率、修正载流，可一键"采用"或"复制"。

### 5.3 异常情况处理

| 异常提示 | 原因 | 解决方案 |
|----------|------|----------|
| 未找到符合条件的规格 | 参数过于严格 | 放宽环境条件或选择更高规格 |
| 请增加片数或调整参数 | 单层母排无法满足 | 启用母排叠加功能 |

## 7. 成本估算与材料替换

### 7.1 单价设定与动态重算

- 直接填入有色金属市场实际采买指导价 (单位：元/kg)
- 系统自动计算：母排截面积 x 材质密度 x 总布线长 x 叠排片数 = 总造价

### 7.2 铜 vs 铝等效对比

以"保持发热与载流绝对一致"为等效前提，自动反推铝排替代方案，高亮显示**潜在节省百分比**与**绝对差价**。

### 7.3 安全策略变更成本预检

将"经济型"硬切为"保守型"时，成本面板会显示价格跳跃，帮助工程师界定安全边界的代价。

## 8. 安全校验 (v2.2+)

### 8.1 短路耐受 (Icw) 校验

- 计算母排在 1 秒内的短时耐受电流
- 超过母排耐受能力时立即报红
- 余量不足 20% 时提示关注上游保护动作时间

### 8.2 电动力与支撑间距

- 依据三相短路峰值电流计算相间电动力 (F)
- 给出建议的最大支撑保护间距，指导绝缘子分布密度

### 8.3 稳态温升预测

- 基于单位长度发热量与散热表面积预测稳态温升
- 热红线：镀锡/裸排 105 C，绝缘母排 90 C
- 显示温升占限值的百分比

### 8.4 PE (接地) 母排自动选型

- 严格遵循 IEC 60364-5-54 规则
- 根据相线截面积自动检索并推荐最小合规 PE 母排规格

## 9. 压降估算

### 输入与输出

填入母排长度后，系统运用电阻率积分计算电压降：

| 压降率 | 状态 | 判定 |
|--------|------|------|
| < 2% | 正常 | 符合标准 |
| 2%-3% | 偏大 | 建议关注 |
| > 3% | 过大 | 需要改善 |

### 改善措施

1. 增大母排截面积
2. 缩短母排长度
3. 增加并联母排数量
4. 改善连接点接触电阻

## 12. 核心算法

### 综合修正系数

```
K = Ktemp x Kalt x Kwind
实际载流量 = 基础载流量 x K
```

### 温度修正

```
Ktemp = sqrt((Tmax - Tamb) / (Tmax - 40))
```

### 海拔修正

```
Kalt = 1 - 0.005 x (H - 1000) / 1000   (H > 1000m)
```

### 风速修正

```
Kwind = 1 + 0.05 x Vwind
```

### 压降公式

```
dV = rho x L x I / S
```

其中 rho 为电阻率（铜：0.0172 Ohm*mm^2/m），L 为长度，I 为电流，S 为截面积。

### 选型算法

1. 获取目标电流值
2. 计算综合修正系数 K
3. 计算允许载流量 = 基础载流 x K
4. 筛选满足条件的规格
5. 按负荷率排序推荐

## 14. 常见问题

### Q1：经济型规格负荷率超过 100%？

这是因为使用了风冷提升系数。良好散热条件下，母排实际载流量可超过标准值。建议优先选择标准型策略确保安全裕度。

### Q2：海拔超过 3000m 时如何选型？

1. 自动应用海拔修正系数
2. 建议选择标准型或保守型策略
3. 加强通风散热措施

### Q3：风扇失效模拟有什么作用？

评估强迫风冷系统失效后的降容风险。启用后显示风冷失效时的载流量，帮助评估系统可靠性。重要场景建议启用。

### Q4：显示"未找到符合条件的规格"？

1. 检查目标电流是否过大
2. 放宽环境条件（降低温度、启用风冷）
3. 启用母排叠加功能
4. 尝试自定义母排验证

### Q5：压降过大？

1. 增大母排截面积
2. 缩短母排长度
3. 增加并联母排数量
4. 改善连接点接触电阻

### Q6：PDF 导出失败？

| 步骤 | 操作 |
|------|------|
| 1 | 检查网络连接 |
| 2 | 尝试其他浏览器 (Chrome/Edge) |
| 3 | 清除浏览器缓存 |
| 4 | 重新打开工具 |
